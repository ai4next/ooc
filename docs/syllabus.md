# 算力起源 · 课程大纲

> 16 章 × 8 关 = 128 关。每章 5 谜 + 2 障 + 1 托，一张 8 行的表。
> 本文是关卡清单的唯一来源：id、顺序、概念、错的直觉、状态。机器、通过条件、★ 指标等逐行规格由 levels.md 据此重建。
> 世界观与结构见 [design.md](design.md)，数据模型见 [圣经 §6.1](../../oo_kit/docs/trilogy-bible.md)。

**读法。**

- 编号 `章-序`：1–3 谜，4 障，5–6 谜，7 障，8 托。障排在它检验的概念之后，委托永远是第 8 关。
- 类：**谜** 解谜 · **障** 故障（先在 Warp River 上指证，再修）· **托** 委托（自由机台，无初始方案，之后展演）。
- 状态：**✓** 已实现（id 与机制不变，只换章节编号）· **E** 旧规格里有、尚未实现（机制沿用 levels 旧稿）· **N** 新增。
- 概念 ≤ 25 字，只写一个概念；“错的直觉”≤ 20 字，是初始方案、预测错误选项或第一次尝试会掉进去的坑。
- 障的最后一列写 Evidence 的 `why` 与指证目标；其余行写 —。`why` 词表见文末。
- 单关目标时长 10–25 分钟（后几章的难关可到 25 分钟）；主线 40–50 h 来自 128 关加 16 次展演。
- 每章 5 谜 / 2 障 / 1 托。旧规格的 48 个 id 全部保留，各章分到的数量不同（第 1、2 章各 6 个，第 7、9、12 章各 1 个），其余关为新增。

## 4. `why` 词表

Evidence 的 `why` 共 23 个，前 22 个各被至少一个障使用；原子争用保留给开放题与展演的诊断。

| 章段 | why |
|---|---|
| 第 1–4 章 | 坐标、溢出、撕裂、寻址、串行、发散 |
| 第 5–6 章 | 冒险读旧值、裁剪、插值 |
| 第 7–9 章 | 缓存缺失、缓存冲突、未合并、bank 冲突 |
| 第 10–12 章 | 竞争、负载不均、占用率、乱序可见 |
| 第 13–16 章 | 累加、饱和、互等、链路争用、静默错误 |
| 保留 | 原子争用 |

指证对象不止“周期 + 车道”：还有 warp、整行缓存、bank、链路、SM、累加器与被读取的掩码车道。`Evidence` 的字段需要加 `link`、`sm`、`addr` 三个可选项，规则表按 `why` 分派。
